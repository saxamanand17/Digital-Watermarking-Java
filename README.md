\# Digital Watermarking Java



A Java-based digital image watermarking application with a graphical user interface (GUI). The project demonstrates image processing and digital watermarking using Java Swing and AWT.



\## Project Overview



Digital watermarking is a technique used to embed information into digital media such as images. This project provides a Java desktop application for working with images and generating watermarked outputs.



\## Features



\- Java-based desktop application

\- Graphical User Interface using Swing

\- Image processing using Java AWT

\- Digital watermarking workflow

\- Image loading and processing

\- Watermarked image generation

\- Sample input and output images



\## Technologies Used



\- Java 17

\- Java Swing

\- Java AWT

\- Image Processing

\- Object-Oriented Programming
